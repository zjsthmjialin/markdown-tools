# MarkAny v1.1.1

运行与转换改进：

- 重复转换同名文件时自动另存，避免覆盖已有 Markdown。
- 混合扫描页和文本页的 PDF 改为逐页提取，并在需要时只对相应页面执行 OCR。
- 转换界面显示 PDF 页级进度；取消后停止继续处理并保留未开始的队列。
- 空内容或不可用 OCR 会明确报错；OCR 部分失败会在输出中留下提示。
- 提取图片按文档分开放置，避免不同文件共用图片文件名。
- 校验源格式选择，转换服务启动失败时明确提示；修正 macOS 关闭窗口后的应用生命周期。

安装包由 GitHub Actions 从同一仓库分别构建 Windows 与 macOS Apple 芯片版本。
